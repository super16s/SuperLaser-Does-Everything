# SuperLaser Social App

Image generation with [Fooocus](https://github.com/lllyasviel/Fooocus), behind
a password login, as an installable phone-friendly web app.

### Run it

```
cp .env.example .env   # set APP_PASSWORD and FOOOCUS_API_URL
npm start
```

Then open http://localhost:3000. No npm dependencies.

### Login

Set `APP_PASSWORD` in `.env` to put the whole app behind a login (signed
HttpOnly cookie, 7 days, 5 wrong attempts locks that IP for 15 minutes). It is
required for image generation. Serve over HTTPS if exposed beyond localhost;
the password is sent in plain text otherwise.

### Image generation (Fooocus)

The "Image Studio" at the top of the page calls a separately-run
[Fooocus-API](https://github.com/mrhan1993/Fooocus-API) server (a community
REST wrapper around [Fooocus](https://github.com/lllyasviel/Fooocus); Fooocus
itself has no stable HTTP API and needs a GPU). Start Fooocus-API somewhere
(`python main.py`, port 8888), then set `FOOOCUS_API_URL` in `.env`. The app
exposes `POST /api/image` with `{ "prompt": "..." }` and returns
`{ images: [{ src, seed }] }`. Unset, the panel just reports it's not
configured. Note Fooocus is in limited-maintenance mode upstream.

**No local GPU?** Open `colab/fooocus_api.ipynb` in Google Colab with a GPU
runtime and run all cells. It installs Fooocus-API, starts it, opens a
Cloudflare quick tunnel and prints the `FOOOCUS_API_URL` to paste into `.env`.
The tunnel URL has no login, so keep it private; it changes every session and
first start downloads ~10 GB of models.

### Install it on your phone (PWA)

The app is a Progressive Web App — run it as usual (`npm start`), open it
in your phone's browser (same network as the machine running it), then:

- **Android/Chrome**: use the browser menu → "Add to Home Screen" (or the
  install prompt Chrome shows automatically).
- **iOS/Safari**: tap the Share icon → "Add to Home Screen".

It then opens full-screen with its own icon, no browser chrome. This is
the same server and code as the desktop version — no separate mobile
build. The app shell is cached by a service worker (`public/sw.js`); generating
images still needs a network connection.

Icons live in `public/icons/`, generated by `scripts/generate-icons.mjs`
(zero image-library dependencies — a minimal hand-rolled PNG encoder).
Re-run it if you ever change the icon design.
